# 作者参考三卡｜不是模型实跑结果
先尝试生成、检查自己的三卡，再对照此文件。措辞不必相同，概念与限定必须一致。

## 卡1：聊天应用
- **正面：** 我打开网页、输入学习材料时，直接使用的是什么？
- **背面：** 聊天应用是人使用的产品入口，呈现对话并按产品设计管理消息、文件或权限。它不是底层模型本身。
- **例子：** 小禾打开聊天网页，粘贴材料并提出三卡要求。
- **易混点：** 网页入口是应用；生成文字的核心组件是模型，不因看到网页就知道精确模型版本。
- **依据：** L1说明入口与管理；L2区分核心组件；L6给出小禾例子。

## 卡2：模型
- **正面：** 在三卡任务里，模型与聊天网页有什么不同？
- **背面：** 模型是把输入变成输出的核心组件，可根据文字和要求生成卡片文字；聊天网页是应用入口，不是模型本身。
- **例子：** 小禾收到的卡片文字由模型参与生成；页面负责呈现对话。
- **易混点：** 模型是核心组件，API是程序请求接口；看到回答不能推知精确模型版本。
- **依据：** L2说明模型与版本边界；L3说明API；L6提供任务例子。

## 卡3：API
- **正面：** API在这里做什么？本次手动做卡需要配置它吗？
- **背面：** API是程序向服务提交请求的接口，用于程序提交材料、接收输出。本次普通文字聊天不需要自行配置API或提供密钥。
- **例子：** 开发者以后若写程序批量发送同类材料、接收回答，就属于材料所说的API用法。
- **易混点：** API不是更聪明的模型；使用API不保证答案更准确。
- **依据：** L3定义接口；L4限定效果；L5说明本课不需要；L6给出例子。
