# 为虚构片头比较两版无歌词音乐候选

两版原始 MP3 候选、听评记录与 20 秒选段建议；不是已剪好的 20 秒成品。

本页根据截至 2026-10-29 的官方资料整理；未附已生成音频，也不表示已在产品运行或听评。

## 1. 准备文字 brief

这次只为虚构科普栏目《小小发现室》比较两版无歌词配乐候选。先阅读或复制下面的 brief 到自己的记录文件；不需要音频输入，也不必上传附件。

**最后应保存什么：** A/B 两份原始 MP3、完整提示记录、空白表填写后的听评、选段建议和未解决问题。只有实际生成后才会有音频文件；本页没有可试听参考音频。

**20 秒是目标选段，不是原始曲长保证。** 当前帮助说明 short 约 1 分钟。精确 20 秒文件仍需另做人工裁剪、淡出、导出与复听；本课不增加剪辑工具链。如果必须立即交付精确 20 秒成品，单靠本课不够。

brief 里的 100 BPM、C 大调、18 秒收束是创作要求，不是已测得的音频事实。没有测量就写“未测”。先看下一步的账号与费用门槛，再决定是否跟做。

### 虚构 brief

```text
项目：虚构科普栏目《小小发现室》片头配乐候选。
用途：后续20秒片头，0–4秒标题出现，4–15秒展示纸飞机与星图，15–20秒栏目名落版。
情绪：温暖、好奇、轻盈，不紧张，不宏大，不像广告促销。
音乐：轻电子与原声混合，4/4拍，约100 BPM，C大调。
固定配器：柔和合成器铺底、轻木质打击乐、温和低音。
唯一A/B变化：主旋律音色。A为毡音钢琴；B为马林巴木琴。
限制：纯器乐；没有歌词、歌唱、哼唱、合唱或口白；不模仿任何歌手/现成歌曲。
目标段：优先让前20秒可用；18秒左右收束，20秒附近留出剪辑空间。
交付：A/B原始MP3、提示记录、20秒选段建议、听评与未解决问题。
不承诺：原始文件严格20秒、指定BPM/调性精确执行、商业版权自动清零。
```

## 2. 确认工具与账号门槛

这条路线只用 [Gemini 官方网页](https://gemini.google.com/) 的 Create music。可播放 MP3 的设备和文本记录工具足够；无需 API key、MCP 或安装 Skill。耳机不是强制，但 A/B 应使用同一监听设备和音量。

开始前逐项确认：

- 年满 18 岁，使用个人 Google 账户，或已获支持的工作／学校账户，并自行登录。不要把密码交给学习助手。
- 所在地区和账户确实支持 Gemini 网页应用。官方地区表将中国大陆标注为 **Workspace only**；不能因为有中文界面就推断大陆个人账户可用。不要绕过地区限制。
- 页面能找到 Create music。没有入口，先查账号、管理员和当前官方帮助，不下载不明客户端，也不改用 API 绕过门槛。
- 音乐帮助要求 Keep Activity 开启。先读隐私说明；不接受保存活动就停在阅读或纸面练习，不为完成课程强行开启。
- 只输入虚构文字，不上传真实客户资料、未发表歌词、人声样本或私人影像。

**本课新增支出预算为 0。** 仅用已有可用额度；不升级套餐、不启用试用、不绑定账单、不购买积分。出现额度通知立即停止，记录“额度阻塞”，等待产品允许恢复后再决定是否继续。功能表列无付费计划也可使用音乐功能，但额度会变化，不能承诺免费无限量或固定次数。

这不是自主作曲 Agent：人写 brief，工具出候选，人负责听评。手动保存模板不会获得音乐模型权限，也不能替代实际听评。

## 3. 准备 A 对话与音乐模式

先确认上一步的账号、地区、隐私与额度条件；未满足就不提交。

1. 打开 Gemini 官方网页，在自己的设备上完成登录。
2. **先新建 A 对话**，再在输入框底部选择 **Upload & tools → Create music**。中文标签可能不同，以当前官方帮助和实际账户界面为准。菜单名字含 Upload，不代表本课要求上传文件。
3. 如果页面有对应选项，长度选 **short**，人声选 **无／Instrumental**；风格可以自定时保留提示中的描述。记录实际显示的长度和选项。
4. 当前帮助的 short 约 1 分钟；full 约 2–3 分钟且需 Pro 模型，本课不选 full。
5. 保持在刚设置好的 A 对话内。**现在先不发送**；下一步复制完整 A 提示。设置后不要另开对话再发送。

任何入口、账号、管理员权限或额度问题都先停止，不为继续练习临时付费或放宽权限。

## 4. 分别生成并下载 A／B 候选

只提交下面的虚构文字，不附加文件、不上传音频。每版发送一次，等待明确结果；请求状态不明时先检查是否已有结果，不反复点击生成。

第一轮 A1 + B1 最多两次提交。额度不足或出现新增费用要求，立即停止。页面设置与提示中的 20 秒安排不保证被精确执行；下载后仍须自己检查。

A/B 只改变提示里的主旋律音色。但独立生成的旋律、节奏或响度可能也变，不能据一次结果认定某种音色必然更好。

## 5. 查看下载与填写听评记录

下面是**空白记录模板，不是音频参考答案或作者成绩**。只有实际生成后才会有 A/B 音频。按文件夹示例保留原始件、提示和 brief；示例中的 MP3 名字不是可下载音频链接。

先确认下载的是可打开、有实际声音的 MP3。记录播放器显示的原始总时长；约 1 分钟不算失败，但不是 20 秒成品。短于 20 秒则不满足本次选段目标。不要把 API 的采样率规格套到 App 文件；看不到的编码参数不要补写。

1. 用舒服的小音量、同一耳机或音箱、同一播放器音量比较。爆音或不适立即停止。不要把更响直接判为更好。
2. 各完整听一遍，确认中途没有词句、口白、哼唱或合唱；再各听 0–20 秒，最后复听 16–22 秒判断截断风险。
3. 可以请伙伴不看提示，把文件随机标为 X/Y 并保留映射；若一个人知道版本，记录“非盲听”，不能自称双盲。
4. 在空白 CSV 中填真实观察。每项评分都配具体时间点或听感；没有响度仪就写主观响度是否相近，不填虚构 LUFS 或 true peak。
5. 格式可用且全曲纯器乐是硬门槛；先过门槛，再比较情绪贴合、前 20 秒结构、结尾衔接（各 1–5 分）。硬门槛失败不能靠总分抵消。

决策模板的“未测”“未制作”是待完成状态，不是实际评测结果。两版都合格且接近时按 brief 偏好选，不必为一个分数继续生成。

## 6. 检查、有限修正与停止

先逐项检查，不只看是否生成了文件：

- 两份原始 MP3 都能打开、有真实声音；保留原始件，不覆盖。
- 全曲没有歌词、口白、哼唱或合唱；出现人声要记具体时间。
- 温暖、好奇、轻盈，符合虚构画面；写出具体位置，不只写“挺好”。
- 前 20 秒没有突兀空白或爆音，18–20 秒有可衔接收束；20 秒正逢强拍或长尾被截，就写“须剪辑处理”。
- 主观无明显失真、爆裂或忽大忽小。主观听评不代替客观响度、峰值测量。
- 没有指定艺人、作品、品牌拟声或未授权输入。发现明显相似旋律，先不对外使用，不能以“AI 生成”放行。

**第一轮 A1 + B1 最多两次。** 有可用候选且足够判断就停止。仅当能写明一个主要问题、账户仍有额度且无新增费用时，才进入第二轮：最多再生成 A2 + B2，总计最多四次提交。**四次只是停止上限，不是四次免费额度保证；任何额度提示都优先停止。**

若必须修正，二选一，将同一句附在 A/B 原提示末尾，其他文字和设置不变：

- 有哼唱：`本次优先修正：彻底去除所有人声成分，包括哼唱、口型采样和合唱垫底，只保留乐器。`
- 20 秒附近难切：`本次优先修正：让主旋律在第18秒附近结束乐句，随后两秒只留衰减的乐器尾音，不要在此处新起一段。`

每一版都**先新开对话，再进入 Create music，重选相同模式、长度与人声选项，最后粘贴完整原提示加修正句**。这是独立生成，不是对旧音频的可逆编辑。A1/B1 仍保留，新文件用 r2 命名；只修一版也可以，但应标“修正候选”，不声称严格配对实验。

第二轮后无论是否满意都停。两版仍不合格，就交付“本次未获得合格候选”及失败点；转人工作曲或剪辑须另定任务，不继续加预算。出错、额度不足、入口不符或安全拒绝即暂停，不绕过限制。状态不明时先检查是否已经有结果，不盲目重复提交。

**保存与回退：** 保留全部原始文件和提示，将不用的版本标为 rejected。没有证据表明删除生成会退还额度或费用；新生成不是恢复上一版，删除聊天不是音频编辑撤销，也不保证删除所有服务端留存。

**候选不等于成品，导出不等于商用无风险。** 精确 20 秒文件尚需人工裁剪、淡出、导出后复听。Google 不主张生成内容所有权，不等于所有输出必然受著作权保护或绝不侵权。对外使用前，核对自己的国家版本条款、生效日期、输入权利、可能相似性、客户要求和 AI 披露规则，并保留生成日期、入口和提示。不要伪装来源欺骗观众；这课不替代法律判断。
