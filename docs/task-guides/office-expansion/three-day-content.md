# 排好三天内容，再写出第一篇样稿

三天内容表、一篇150—220汉字样稿、发布前检查和依据说明；只写文字，不配图、不发布。

适合：品牌运营、内容编辑；适合已有产品事实、还没开始排期的人。

- 不需要安装Skill；提示词已包含这一次的要求。

打开客户端点“登录”，在自动打开的官网页面选择可用的登录方式（如微信扫码）；由你本人完成，密码和验证码不发给AI。成功后回到客户端的创建任务页。

先确认账户可用额度。本页不承诺免费；如果暂时不能安装或登录，先打开下载的文本，读提示词和参考结果做纸面练习，这不等于完成了产品任务。

只用虚构练习材料，不上传真实客户资料。AI服务可能消耗现有额度；账号功能、地区和组织许可需本人确认。没有额度时停止，不自动购买。首次安装与登录均由读者自行操作；暂不具备条件可做纸面练习，不能记为产品执行成功。

## 7. 检查与修正

- 日历恰好覆盖2026-11-09、10、11，平台都是品牌自有公众号。

- 正文只按汉字计数，须150—220字；标题、独立CTA、依据不计入。

- 参数只能是420g、USB-C、129元；不得肯定宣传护眼、12小时续航或销量第一。

- A1照片未获许可；配图只能留文字需求，不能成为待发布素材。

- 字数不符：回复“只改正文到150—220汉字，标题、CTA、依据分开；保留B1事实，不扩充功效。”

- 出现夸大或照片安排：回复“依据B2删掉未验证功效；A1不可使用。把图片改为待审批的文字需求，不生成素材。”

- 日期缺一天：回复“只修calendar.csv，补齐11月9、10、11日，每天一行，均为草稿待审。”
