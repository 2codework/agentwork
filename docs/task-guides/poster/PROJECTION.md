# 公开教学投影与素材身份

本目录保留已接受读者包的全部原文件字节：四份说明与七份素材/字段文件。before.png 与 after-authored.png 均为作者编写的合成海报；后者仅是理想对照，不是ChatGPT实跑输出。真实输出须由学习者实际操作后另存并独立记录来源。

## 派生规则
- workflow.json 将原GUIDE的第1至6步依次绑定到prepare/tool/setup/prompt/example/check；只改阅读标题与包内链接公开基址，原正文不扩展产品保证。
- prompt.txt 与 correction-prompt.txt 分别从原GUIDE的两个text代码块原字符提取，含原末尾换行。展示时拆成前文、可复制原提示、后文。
- source-ledger.json 从读者来源页及GUIDE提取正式HTTPS链接，去重，保留核验日期；不把日期写成产品发布日期或新增实跑证据。
- 原GUIDE、README、SOURCES、CHECKLIST及assets全部原字节；未把技术素材对照改写成产品成功率或学习者验收成绩。
