# 发布质量门禁

## 已实现自动检查

- Python schema：案例 ID 唯一、非空字段、步骤、证据一致性、来源链接安全。
- Python 构建可重复；无外部脚本/样式依赖；禁止动态 innerHTML/eval。
- Node 语法及进度导入格式、无效版本、未知 ID、恶意键测试。

## 每次发布必须人工完成

- 检查每条主张与来源对应，记录核查日期；链接可打开不代表内容被证实。
- 320/390/768/1440 像素布局、键盘操作、焦点顺序、屏幕阅读器标签、对比度。
- 空搜索、无匹配、重复打卡、取消打卡、刷新持久化、存储禁用、损坏本地记录、导入取消/错误/超限/重复、导出→恢复、清除确认。
- 项目子路径资源加载、JSON 加载失败提示、中文字符和长链接折行。
- 确认无私密/真实个人数据、凭据、旧项目内容，许可范围正确。
- 目标组织与仓库权限、公开范围确认；发布后核对准确 commit、CI 与实际 Pages URL。

当前不能仅因构建和单元测试通过就声称浏览器 QA 或公开部署已通过。
