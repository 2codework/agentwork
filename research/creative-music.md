## 概念与证据边界
模型是推理技术；插件/API 是执行工具；有计划、状态、限额、工具调用与验收的编排才是 Agent 工作流。本包是人类监督的 Agent 设计，不把音频产品都改称自主 Agent。全部输入与提示原创，绝不复制受版权歌词或未经授权克隆真人。

## 技术节点与许可边界

- **MusicGen v1** (`music-musicgen`, model)：离散音频 token 自回归音乐生成，学习文本和旋律条件。 代码 MIT / 权重 CC-BY-NC 4.0；仅按许可允许的非商业研究使用
- **JASCO v1** (`music-jasco`, model)：Flow Matching 加入时间局部和弦、鼓与旋律控制。 代码 MIT / 权重 CC-BY-NC 4.0
- **Stable Audio Open 1.0** (`music-stable-audio-open`, model)：开放权重音效与音频生成；不等同于当前云服务版本。 特定模型许可优先；不以开权重或订阅推出商用授权
- **HTDemucs v4** (`music-demucs`, model)：波形/频谱混合模型分离人声、鼓、贝斯及其他。 需复核模型与依赖许可；分轨不消除原曲权利
- **Whisper** (`music-whisper`, model)：多语种 ASR、语音翻译与语言识别。 代码与权重 MIT；语料录音仍需同意
- **gpt-4o-transcribe-diarize** (`music-diarize`, model)：说话人标签转写的旧 API 专用模型。 API 计费；上传前取得录音/数据处理许可
- **Lyria 3.5 / Clip** (`music-lyria`, model)：Gemini API 音乐生成；Clip 预览与完整歌曲模型区分。 云 API 额度与服务条款；输出权利不等于版权登记保证
- **Suno generation service** (`music-suno`, tool)：歌曲/歌词/编曲产品入口，底层版本与下载政策需分开记。 付费/免费和生成/下载日期分列，发行前确认现行条款与权益
- **Neutron 5 Mix Assistant** (`music-neutron`, tool)：轨道混音建议与处理，供人类监听修改。 商业插件；未购买/未安装；参考素材须有权
- **Ozone 12 Master Assistant** (`music-ozone`, tool)：母带处理建议和信号链，不替代听感判断。 商业插件；不承诺固定价格；禁止盗版
- **Auphonic multitrack** (`music-auphonic`, tool)：语音多轨自适应后期和混音输出。 按服务额度/时长核账；上传受隐私与合同限制
- **ElevenLabs SFX** (`music-eleven-sfx`, model)：文本描述生成音效，含时长与循环控制。 按时长/credits 预算；素材/发行权另审
- **ElevenLabs TTS** (`music-eleven-tts`, model)：文字到语音；仅使用有合法授权的产品内置或设计声线。 付费额度与声线使用条件复核；不克隆、冒充真人
- **Accessible captions QA** (`music-captions`, standard)：同步语音和必要非语音文字信息；自动输出需人工核对。 人工校对成本；录音和转写均需最小化访问
- **Magenta RealTime 2** (`music-mrt2`, model)：交互式实时音乐生成；v1 为 legacy 分支。 代码 Apache-2.0；权重许可未完成独立审查，商用待确认
