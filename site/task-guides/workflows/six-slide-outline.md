# 把一段复盘材料变成6页汇报大纲

6页逐页大纲：每页标题、3个要点、画面建议、讲稿。先不纠结排版。

适合：需要先向主管确认内容、再做PPT的运营或行政。

## 1. 准备什么

- 先有能联网的电脑和你获准使用的产品账号。没有客户端请按下面“第一次打开”操作；本教程没有替你安装、登录或购买。

- [下载 brief.txt](inputs/six-slide-outline/brief.txt)

### 输入全文（也可直接复制）

#### brief.txt
```text
虚构练习｜春芽书店会员活动试点复盘
听众：店长。演讲：5分钟。目的：申请下一轮1500元预算，不代表已获批。
试点：2026年10月，两场活动。报名43人，到场35人，收入1200元，支出900元。
问卷：发出30份，有效回复12份；8份希望增加周末场，4份希望增加亲子场。仅代表这12份回复。
问题：第一场签到排队；第二场提前分组后缓解。没有计时数据。
下轮方案：两场周末活动，先预约后签到；设计一场亲子主题。
风险：样本小；新活动可能报名不足；没有与上月的可比数据。
建议：先批准预算上限1500元，每场结束记录报名、到场、收入、支出和反馈。

```

## 2. 用什么，不用什么

WPS 灵犀专业版

- 工具：不需要额外工具；用产品自带对话和文件上传。

- MCP：不需要。MCP 是连接外部系统的接口，这次不连接任何公司系统。

- Skill：不需要安装 Skill；先把这一次做对，再考虑保存重复流程。

## 3. 打开哪里，怎么开始

### 第一次打开

- 还没有软件：由你本人打开 [WPS灵犀官网](https://www.lingxi.cn/)，从“下载 灵犀专业版”进入 [官方下载页](https://www.lingxi.cn/download)，选择匹配系统的包。官方指南推荐Windows 10+；公司电脑先确认安装许可。

- 按 [快速开始](https://www.lingxi.cn/docs) 完成安装后，由你本人使用WPS账号或页面提供的验证码等方式登录，再到左上角“+”开始。不要把账号凭据发给AI。

- 官网也有“使用网页版”入口（https://lingxi.kdocs.cn），官方说明支持对话和文档处理；可先在那里练习文字大纲。但本页的“+”、附件和可编辑PPT步骤按专业版桌面文档编写，不把桌面全部能力照搬到网页。

- 先确认智点与功能权益；不能使用时先读完整样稿，不为练习被动购买。

### 已经可以使用，开始任务

1. 打开已有的 WPS 灵犀专业版，点击左上角“+”新建任务。

2. 点输入框旁的附件按钮，选择本页的小输入文件；也可以将文件拖进对话框。

3. 粘贴本页完整提示词，发送。无须去找模板、插件市场或模型 API。

4. 在对话中看结果；如果生成了文件，点击文件链接下载，再用你已有的办公软件打开检查。

只用虚构练习材料，不上传真实客户资料。AI服务可能消耗现有额度；账号功能、地区和组织许可需本人确认。没有额度时停止，不自动购买。首次安装与登录均由读者自行操作；暂不具备条件可做纸面练习，不能记为产品执行成功。

## 4. 复制这段提示词

```text
请根据附件 brief.txt，写一份给店长看的6页演示大纲，讲5分钟。只输出大纲文字，不要声称已生成PPT文件。每页必须有标题、最多3个要点、一个画面建议、约40至70字讲稿。六页依次为：结论与请求、参与情况、收支、反馈与问题、下一轮安排、预算决策与风险。区分事实、建议、待批准事项。计算到场率及收入减支出差额；不要把差额称作净利润。问卷只代表12份有效回复，不能推广到所有会员。没有计时数据，不写排队改善百分比；没有上月数据，不写环比。
```

## 5. 完整参考结果

示例由作者编写，步骤据2026-10-29官方文档；未在产品内执行。

## 第1页｜申请下一轮1500元预算上限
- 本轮完成2场会员活动。
- 建议继续小规模试点，不直接扩大。
- 请求批准下一轮预算上限1500元，尚未批准。
画面：左侧试点结论，右侧突出“待批准：1500元”。
讲稿：这次先汇报两场活动的实际结果，再说明下一轮安排。我们建议继续小规模验证，今天请求的是1500元预算上限，并不是宣告预算已经获批。

## 第2页｜43人报名，35人到场
- 两场合计报名43人。
- 合计到场35人。
- 到场率81.4%（35÷43）。
画面：报名43与到场35两根同刻度柱形条。
讲稿：两场活动共报名43人，实际到场35人，到场率约81.4%。这里是合并人数后的比例，不是两场比例的平均值，也没有与上月比较。

## 第3页｜收入1200元，支出900元
- 收入1200元。
- 支出900元。
- 本次记录的收支差额300元。
画面：收入、支出两张数字卡和差额算式。
讲稿：现有记录显示收入1200元、支出900元，差额300元。材料没有提供完整成本口径，因此这里只称收支差额，不将它写成净利润。

## 第4页｜反馈指向周末场，样本仍小
- 有效问卷12份：8份希望增加周末场，4份希望增加亲子场。
- 第一场出现签到排队。
- 第二场提前分组后有所缓解，但无计时数据。
画面：12份反馈分成8与4两组；另列签到问题。
讲稿：反馈来自12份有效问卷，不代表所有会员。周末和亲子主题值得继续验证。提前分组后排队有所缓解，但没有计时记录，不能量化改善幅度。

## 第5页｜下一轮仍做两场
- 安排两场周末活动。
- 先预约后签到，减少现场信息核对。
- 其中设计一场亲子主题。
画面：两场活动时间线，日期标“待定”。
讲稿：下一轮建议仍以两场为限，保留先预约后签到的安排，并试做一场亲子主题。具体日期尚未确定，需结合场地和人员安排另行确认。

## 第6页｜批准预算后再推进
- 待决策：预算上限1500元。
- 风险：样本小、报名可能不足、无上月可比数据。
- 每场记录报名、到场、收入、支出和反馈。
画面：决策框与五项记录清单。
讲稿：请店长决定是否批准1500元预算上限。若获批，我们将逐场记录这五项数据，再判断是否继续。若报名不足，先调整安排，不直接追加支出。


## 6. 怎么检查，出错怎么办

- 刚好6页，每页不超过3个要点；数字43、35、1200、900、300一致。

- 1500元只能写申请或待批准；300元不能叫净利润。

- 反馈范围限定12份，排队改善没有虚构百分比。

- 只有通篇长文：回复“请拆成编号1至6的六页，每页补齐标题、要点、画面和讲稿”。

- 想要真正PPT：先审完大纲，再用下面的可选升级；文件没生成时仍只算大纲完成。
