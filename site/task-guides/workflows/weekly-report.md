# 把五天零散记录写成一份周报

一份可直接复制到邮件的周报，包含数字、卡点、下周计划；不替你发送。

适合：每周要向主管汇报的运营、销售助理或行政。

## 1. 准备什么

- 先有能联网的电脑和你获准使用的产品账号。没有客户端请按下面“第一次打开”操作；本教程没有替你安装、登录或购买。

- [下载 week-notes.txt](inputs/weekly-report/week-notes.txt)

### 输入全文（也可直接复制）

#### week-notes.txt
```text
虚构练习｜运营助理林青｜2026-10-19至10-23
本周目标：清理会员资料、完成两场活动、准备下周报名页。
周一：整理会员资料80条，发现重复6条，已请店长确认，尚未删除。
周二：完成读书会，报名18人，实际到场15人。
周三：完成作者分享会，报名25人，实际到场20人。
周四：报名页文案完成，设计图未收到，无法上线。陈禾说下周一12点前给图。
周五：发出会员问卷30份，收到12份有效回复。没有上周可比数据。
下周计划：拿到设计图后检查并上线报名页；跟进6条疑似重复资料；整理问卷意见。
需要店长帮助：确认6条疑似重复是否合并，最晚希望下周二回复。

```

## 2. 用什么，不用什么

腾讯 WorkBuddy

- 工具：不需要额外工具；用产品自带对话和文件上传。

- MCP：不需要。MCP 是连接外部系统的接口，这次不连接任何公司系统。

- Skill：不需要安装 Skill；先把这一次做对，再考虑保存重复流程。

## 3. 打开哪里，怎么开始

### 第一次打开

- 还没有软件：由你本人打开 [WorkBuddy 官网](https://www.workbuddy.cn/)，点“立即下载”并选择你的系统。Windows 10及以上的x64设备可按 [官方安装图解](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Installation-Win-Guide) 完成；公司电脑先取得安装许可，不关闭安全软件。

- 打开客户端点“登录”，在自动打开的官网页面选择可用的登录方式（如微信扫码）；由你本人完成，密码和验证码不发给AI。成功后回到客户端的创建任务页。

- 先确认账户可用额度。本页不承诺免费；如果暂时不能安装或登录，先打开下载的文本，读提示词和参考结果做纸面练习，这不等于完成了产品任务。

### 已经可以使用，开始任务

1. 打开已有的 WorkBuddy 桌面客户端，进入创建任务页。

2. 本练习只处理一个小文件：将下方输入文件拖进输入框；不选择整个桌面或公司共享盘。

3. 把下方提示词完整复制到同一输入框并发送。

4. 先在对话中检查全文；需要文件时在右侧结果区查看产物。不要只看“已完成”三个字。

只用虚构练习材料，不上传真实客户资料。AI服务可能消耗现有额度；账号功能、地区和组织许可需本人确认。没有额度时停止，不自动购买。首次安装与登录均由读者自行操作；暂不具备条件可做纸面练习，不能记为产品执行成功。

## 4. 复制这段提示词

```text
请只用附件 week-notes.txt，为运营助理林青写本周周报，面向店长。标题注明2026-10-19至10-23。正文分“本周完成、当前卡点、下周计划、需要支持”，控制在500字以内。两场活动报名数和到场数可相加，写清到场率的分子分母，百分比保留1位小数。问卷回复率另算，不能和活动混在一起。未上线、未合并必须保留。没有上周数据，不写环比增长，不添加积极形容词或编造业绩。将相对日期换成日期，直接输出周报，不发送邮件。
```

## 5. 完整参考结果

示例由作者编写，步骤据2026-10-29官方文档；未在产品内执行。

# 运营周报｜林青｜2026-10-19—10-23

## 本周完成
- 整理会员资料80条，发现6条疑似重复，尚未删除或合并。
- 完成读书会和作者分享会：合计报名43人、到场35人，到场率81.4%（35÷43）。
- 完成报名页文案。
- 发出问卷30份，收到有效回复12份，回复率40.0%（12÷30）。暂无上周数据，不作环比比较。

## 当前卡点
报名页设计图未收到，页面尚未上线。陈禾预计10月26日12:00前交图。

## 下周计划
收到设计图后检查并上线报名页；跟进6条疑似重复资料；整理问卷意见。

## 需要支持
请店长确认6条疑似重复资料是否合并，希望10月27日前回复。


## 6. 怎么检查，出错怎么办

- 35÷43约81.4%，不是两场到场率的简单平均。

- 设计图未收到、报名页未上线、重复资料未合并三点不能被“优化”掉。

- 文案中不能出现“较上周增长”。

- 出现夸张表述：回复“删除没有原始记录支持的成绩和评价，只保留事实”。

- 数字不对：回复“重新按18+25与15+20计算，列出算式；不要改原始人数”。
