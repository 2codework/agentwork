# 七个内容阶段无损映射到六步阅读器

不增加或修改UI。本目录仍保留七个来源阶段，供未来接入时映射：

|六步阅读器|来源阶段|要求|
|---|---|---|
|准备材料|prepare|保留全部输入全文与下载|
|用什么／第一次打开|tools|保留工具、MCP、Skill、首次使用、费用条件|
|打开并附材料|setup|隐私提醒在附材料前；不发送|
|复制提示词并发送|prompt|完整提示词；拒绝写入和外部动作|
|查看结果与参考（example）|result + example|先单独标“查看你自己的结果”，再标“作者完整参考（未在产品运行）”；两组内容不可混淆|
|检查与修正|check|保留全部检查及修正语句|

合并只改变显示分组，不缩减交付：10份参考文件正文、独立下载、参考ZIP全部保留。每个来源阶段内容呈现一次。实际结果观察明确只检查对话内容并由读者审核后手工保存；参考文件下载不能冒充产品生成结果。来源说明仍为次级信息。
