# 音乐入门资料的公开转换说明

此目录将一份已冻结研究稿转换为六步读者课程。原始研究包保留不变；公开目录不包含研究过程记录、内部审计和协作说明。

- 六份文字模板（brief、A/B 提示、空白听评 CSV、决策模板、文件夹示例）按原字节公开；它们不是实际生成产物。
- `workflow.json` 重新组织为准备、工具、设置、提示、观察记录、检查六步；`reader.md` 是同一内容的连续阅读版。保留账号／地区／年龄／活动保存／额度门槛、原始曲长与目标选段差异、纠错与停止边界。
- `source-ledger.json` 保留正式来源链接、定位、短引文、支持范围与核查日期；移除内部核对过程字段，将条款地区差异改写为读者应核对自己适用版本的说明。非本课操作的 API 资料仅作为来源背景，不能视为本课替代入口。
- 不公开研究盘点、修订记录、研究差分、内部验收报告及完整原稿。原稿中非本课必要的 API 比较细节不进入六步主线。
- 本目录没有音频文件、预填听评分数或产品运行成功证据。`product_execution: not_run`、`audio_generated: false`、`listening_test: not_run`。

`projection.json` 记录原包 manifest 和原文哈希、模板原字节绑定、公开文件哈希及被省略项，供复核转换范围；它不表示实际运行过产品。
